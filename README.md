# Gráfico de Despesas

Aplicativo desktop em Python com Tkinter e Matplotlib para agrupar valores por categoria e visualizar as despesas em um gráfico. Os dados ficam em memória durante a sessão.

## Executar

Com Python e Tkinter instalados, abra o terminal na pasta do repositório:

```sh
python -m pip install matplotlib
python cod.txt
```

O arquivo [`cod.txt`](cod.txt) contém código Python e pode ser passado diretamente ao interpretador.
